# PR1 파일럿 안내 — 스카·공원용 1페이지

## PR1은 무엇인가요?

PR1은 **스터디카페와 공원에서 휴대폰을 맡기고, 대신 수신기를 받아 소리만 듣는 시스템**입니다.

한 줄로 말하면:

> 폰은 맡기고, 수신기로 소리만 듣는 구조입니다.

기존 이어폰과의 차이는 분명합니다. 이어폰은 휴대폰이 여전히 손, 주머니, 책상 위에 있습니다. PR1은 휴대폰을 송신기/보관 장치에 맡기고 수신기만 사용합니다.

---

## 어떤 문제를 확인하나요?

### 스터디카페 / 독서실

공부할 때 음악, 백색소음, 강의, 타이머가 필요하지만 휴대폰이 옆에 있으면 집중이 깨집니다.

PR1은 휴대폰을 자리에서 떼어내고, 필요한 소리만 남기는 방식이 실제로 쓸 만한지 확인합니다.

### 공원 / 산책 / 러닝

공원에서 걷거나 뛸 때 휴대폰을 들고 다니기 불편하고, 화면을 계속 보게 되는 경우가 있습니다.

PR1은 휴대폰을 거점에 맡기고 수신기만 가지고 움직이는 방식이 가능한지 확인합니다.

---

## 파일럿은 어떻게 진행되나요?

### 기본 흐름

1. 사용자가 휴대폰을 PR1 거점에 맡깁니다.
2. 사용자는 번호가 매칭된 수신기를 받습니다.
3. 이용 중에는 수신기로 소리만 듣습니다.
4. 끝나면 수신기를 반납합니다.
5. 매칭된 휴대폰을 돌려받습니다.

```text
휴대폰 맡김 → 수신기 받음 → 소리만 듣기 → 수신기 반납 → 휴대폰 찾기
```

---

## 초기 테스트에서 확인할 것

### 사용자 관점

- 휴대폰을 맡기는 것이 실제로 가능한가
- 수신기만 있어도 필요한 소리를 충분히 들을 수 있는가
- 휴대폰 화면을 못 보는 상태가 불편한가, 오히려 좋은가
- 수신기 크기·무게·착용감은 괜찮은가
- 다시 사용할 의향이 있는가

### 운영자 관점

- 휴대폰과 수신기 매칭이 안전한가
- 직원 업무가 너무 늘어나지 않는가
- 분실·파손·개인정보 우려가 어느 정도인가
- 충전·위생·보관·반납이 운영 가능한가
- 유료 옵션 또는 차별화 서비스로 의미가 있는가

---

## 현재 단계

현재 PR1은 판매용 완제품이 아니라 **시제품 검증 단계**입니다.

테스트 목적은 완성품을 홍보하는 것이 아니라 다음 질문에 답하는 것입니다.

> 사용자가 실제로 폰을 맡기고 수신기만 쓸 것인가?

좋은 평가보다 **왜 안 쓸지**가 더 중요합니다.

---

## 운영 장소별 테스트 예시

### 스터디카페 테스트

- 30분~2시간
- 휴대폰 보관/매칭 방식 테스트
- 수신기로 음악, 백색소음, 강의, 타이머 오디오 확인
- 사용 후 집중감·불편함·재사용 의향 인터뷰

### 공원 테스트

- 10~30분 걷기/러닝
- 휴대폰을 고정 거점에 맡기고 수신기만 사용
- 거리, 끊김, 휴대성, 반납 흐름 확인
- 사용 후 불안감·편의성·재사용 의향 인터뷰

---

## 개인정보·보관 안전

PR1의 가장 큰 신뢰 포인트는 휴대폰 보관입니다.

파일럿 전 반드시 정해야 합니다.

- 휴대폰과 수신기 번호 매칭 방식
- 보관 위치와 접근 권한
- 분실·파손 책임 범위
- 사진·영상·녹음 여부
- 개인정보 수집 여부

동의 없이 사용자의 휴대폰 화면, 알림, 개인정보를 보거나 수집하지 않습니다.

## 테스트 종료 후 질문

1. 실제로 폰을 맡길 수 있었나요?
2. 맡기는 과정에서 가장 불안했던 점은 무엇인가요?
3. 수신기만으로 필요한 소리를 충분히 들었나요?
4. 기존 이어폰이나 앱차단보다 나은 점이 있었나요?
5. 다시 쓴다면 스카와 공원 중 어디가 더 맞나요?
6. 돈을 낸다면 어떤 방식이 자연스러운가요?
7. 도입하지 않을 가장 큰 이유는 무엇인가요?

## 연락 시 설명 문장

> PR1은 이어폰이 아니라 휴대폰과 수신기를 맞교환하는 시스템입니다. 스터디카페나 공원에서 휴대폰을 맡기고 수신기만 사용했을 때 실제로 집중과 편의성이 좋아지는지 작은 테스트를 해보려 합니다.
