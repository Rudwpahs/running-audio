# PR1 모두의 창업 준비 패킷

Date: 2026-08-16

목표: 모두의 창업 또는 청소년 창업 관련 제출자료에서 PR1을 이상한 말로 포장하지 않고, 정확한 구조로 설명한다.

---

# 1. 한 줄 설명

> PR1은 스터디카페와 공원에서 사용자가 휴대폰을 맡기고, 대신 수신기를 받아 소리만 듣는 시스템입니다.

---

# 2. 문제

## 스터디카페

공부할 때 음악, 백색소음, 강의, 타이머가 필요해서 휴대폰을 켜는 경우가 많습니다. 하지만 휴대폰이 자리 근처에 있으면 카톡, 인스타, 유튜브 쇼츠, 게임, 검색으로 쉽게 빠집니다.

기존 이어폰은 소리를 무선으로 들려주지만, 휴대폰은 여전히 책상 위나 주머니에 남아 있습니다.

## 공원

공원에서 걷거나 뛸 때 음악이나 운동 오디오를 듣고 싶지만, 휴대폰을 손에 들거나 주머니에 넣고 다니면 불편하고 화면을 계속 보게 됩니다.

기존 이어폰은 소리만 편하게 할 뿐, 휴대폰을 몸에서 떼어내지는 못합니다.

---

# 3. 해결

PR1은 휴대폰을 송신기/보관 장치에 맡기고, 사용자는 작은 수신기만 받아 사용하는 방식입니다.

```text
휴대폰 맡김 → 수신기 받음 → 소리만 듣기 → 수신기 반납 → 휴대폰 찾기
```

수신기에는 화면, 앱, 알림이 없습니다. 필요한 소리만 들을 수 있습니다.

---

# 4. 기존 제품과의 차이

| 구분 | 기존 이어폰 | PR1 |
|---|---|---|
| 휴대폰 위치 | 내 손, 주머니, 책상 위 | 송신기/보관 장치에 맡김 |
| 화면 접근 | 바로 가능 | 바로 보기 어려움 |
| 핵심 기능 | 소리를 무선으로 듣기 | 휴대폰을 맡기고 소리만 가져가기 |
| 사용 장소 | 개인이 아무 곳에서 사용 | 스터디카페와 공원 같은 공간 기반 |
| 문제 해결 | 듣기 편의성 | 휴대폰 접근 자체를 줄임 |

---

# 5. 첫 시장

## 1차: 스터디카페 / 독서실

- 공부 중 오디오가 필요하지만 휴대폰 화면은 멀리하고 싶은 사람
- 집중 좌석, 휴대폰 보관, 프리미엄 집중 서비스와 연결 가능

## 2차: 공원 / 산책 / 러닝

- 폰을 들고 다니지 않고 음악·타이머·운동 오디오만 듣고 싶은 사람
- 공원 거점, 러닝 코스, 걷기 프로그램과 연결 가능

---

# 6. 현재 진행 상황

- PR1 구조 재정의 완료: 휴대폰 ↔ 수신기 맞교환 시스템
- 설문 배포 완료
- 사용자 반응 수집 중
- 송신기/수신기 기반 오디오 전송 시제품 준비 중
- 스터디카페와 공원 사용 장면 중심으로 자료 재작성 중

---

# 7. 시제품 검증 계획

## 기술 검증

1. 송신기와 수신기 간 기본 데이터 전송
2. 오디오 전송 테스트
3. 짧은 거리에서 안정성 확인
4. 스터디카페/공원 거리 조건 테스트

## 사용 검증

1. 사용자가 실제로 휴대폰을 맡길 수 있는지 확인
2. 수신기만으로 필요한 오디오를 들을 수 있는지 확인
3. 수신기 반납과 휴대폰 반환 과정이 안전하고 편한지 확인
4. 다시 사용할 의향이 있는지 확인

- 케이스/수신기 형태 테스트
- 휴대폰 보관/매칭 구조 테스트
- 사용자 체험 운영
- 안전·규제·IP 상담

# 9. 3분 발표 구조

## 0:00–0:30 문제

스터디카페에서 공부할 때 소리는 필요한데, 휴대폰 화면 때문에 집중이 깨집니다. 공원에서도 소리는 듣고 싶지만 휴대폰을 들고 다니면 자꾸 보게 됩니다.

## 0:30–1:10 해결

PR1은 휴대폰을 송신기/보관 장치에 맡기고, 대신 수신기를 받아 소리만 듣는 시스템입니다.

## 1:10–1:50 차별점

기존 이어폰은 휴대폰이 여전히 옆에 있습니다. PR1은 휴대폰 자체를 멀리 둡니다. 이어폰 대체품이 아니라 휴대폰과 수신기를 맞교환하는 구조입니다.

## 1:50–2:30 검증

설문과 인터뷰로 실제로 휴대폰을 맡길 의향이 있는지 확인하고, 송신기와 수신기로 오디오가 안정적으로 전달되는지 테스트합니다.

## 2:30–3:00 계획

먼저 스터디카페와 공원에서 작은 테스트를 진행하고, 사용자가 다시 쓰고 싶은지와 운영자가 관리할 수 있는지를 확인하겠습니다.
