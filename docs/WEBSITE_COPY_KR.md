# 6. How it works

## Title

작동 방식

### 1. 맡기기

사용자가 스터디카페나 공원 PR1 거점에서 휴대폰을 맡깁니다.

### 2. 받기

사용자는 휴대폰 대신 번호가 매칭된 PR1 수신기를 받습니다.

### 3. 듣기

수신기에서는 음악, 강의, 타이머, 운동 오디오처럼 필요한 소리만 나옵니다.

### 4. 반납하기

이용이 끝나면 수신기를 반납하고, 매칭된 휴대폰을 돌려받습니다.

# Website design notes

## Visuals to show

- A clear exchange counter/station
- Phone going into station
- Numbered receiver coming out
- Study cafe desk with receiver only
- Park walker/runner with receiver only
- No phone in hand

## Visuals to avoid

- Earbud product hero shot only
- Generic wireless waves
- Huge outdoor broadcast tower
- Group-tour guide image as the main image
- Abstract futuristic UI
- “digital wellness” stock imagery

## Navigation

Recommended top nav:

- 구조
- 스카
- 공원
- 테스트 현황
- 설문

## Tone

Use simple direct Korean. Do not use startup-cliché words such as:

- 혁신 플랫폼
- 디지털 웰니스
- 미래형 오디오
- 스마트 집중 솔루션
- 청소년 집중 생태계

PR1 should sound like a real thing someone can use at a study cafe or park.
