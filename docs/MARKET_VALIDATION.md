# PR1 Market Validation — Phone Deposit First

Date: 2026-08-16

This document replaces the older buyer-validation plan for outdoor group audio. PR1 must now validate the **phone ↔ receiver exchange** behavior in study cafes and parks.

---

# 1. Core validation question

PR1 is not validated by asking whether people like wireless audio.

PR1 is validated only if people accept this behavior:

> I leave my phone at a PR1 station and use a receiver for audio only.

## Main question

> Will users actually hand in their phone if they can still hear the audio they need?

---

# 2. Target segments

## Segment A — Study cafe / 독서실 users

### User hypothesis

A study cafe user needs audio for music, white noise, lectures, timer, or short alerts, but the phone screen harms focus.

### Operator hypothesis

A study cafe operator may want a phone-free focus option, premium seat/service, or differentiation from competitors.

### What to validate

- Does the user have a repeated phone distraction problem?
- Does the user still need audio while studying?
- Would the user hand in the phone for a receiver?
- Would the operator manage the exchange process?

## Segment B — Park walkers / runners

### User hypothesis

A park user wants audio while walking/running/resting, but does not want to carry or check the phone.

### Operator hypothesis

A park program, event, or local partner may run a receiver rental/deposit point.

### What to validate

- Does the user want phone-free walking/running audio?
- Would the user leave the phone at a station?
- How far from the station does the user need to move?
- Does the return process feel safe and convenient?

---

# 3. Survey interpretation

The existing Google Form should be interpreted through these filters.

## Important survey signals

- respondent uses study cafe / 독서실 / library
- respondent uses parks / walking / running
- phone distraction occurs weekly or more
- respondent needs audio during the activity
- respondent says audio-only receiver is useful
- respondent is willing to test a prototype
- respondent accepts phone deposit or receiver exchange

## Weak signals

- “좋은 아이디어다”
- “있으면 쓸 수도 있다”
- general interest in music or earbuds
- interest in wireless audio without phone deposit

## Strong signals

- “폰을 맡겨도 된다”
- “스카에서 실제로 써보고 싶다”
- “공원에서 뛰거나 걸을 때 써보고 싶다”
- “체험 테스트를 하겠다”
- operator agrees to discuss workflow

# 4. User interview script

Do not start with product explanation. Start with behavior.

## Study cafe user questions

1. 최근 한 달 동안 공부할 때 휴대폰 때문에 집중이 깨진 적이 몇 번 있었나요?
2. 그때 휴대폰을 왜 켰나요? 음악, 강의, 타이머, 연락, 검색 중 무엇이었나요?
3. 공부 중 오디오가 실제로 필요한가요, 아니면 없어도 되나요?
4. 현재는 휴대폰을 어떻게 멀리 두려고 하나요?
5. 폰을 보관함이나 카운터에 맡긴 적이 있나요? 불편하거나 불안한 점은 무엇이었나요?
6. 휴대폰을 맡기고 대신 수신기를 받아 소리만 듣는다면 실제로 해볼 수 있나요?
7. 못 한다면 가장 큰 이유는 무엇인가요?
8. 체험한다면 몇 시간 정도가 적당한가요?
9. 돈을 낸다면 1회 이용료, 월 이용료, 좌석 옵션 중 무엇이 자연스러운가요?
10. 시제품이 나오면 실제로 테스트할 의향이 있나요?

## Park user questions

1. 공원에서 걷거나 뛸 때 휴대폰을 어디에 두나요?
2. 휴대폰을 들고 다니는 게 불편했던 적이 있나요?
3. 공원에서 소리만 듣고 싶었던 상황이 있나요?
4. 휴대폰을 입구나 거점에 맡기고 수신기만 들고 움직일 수 있나요?
5. 어느 정도 거리까지 움직여야 의미가 있나요?
6. 폰을 맡기는 데 가장 걱정되는 점은 무엇인가요?
7. 수신기는 어떤 형태가 가장 덜 귀찮나요?
8. 10~20분 체험을 한다면 해볼 의향이 있나요?
9. 유료라면 어느 방식이 나은가요? 1회 / 월 / 프로그램 포함 / 무료 부가서비스
10. 이 아이디어가 쓸모없다면 가장 큰 이유는 무엇인가요?

# 5. Operator interview script

## Study cafe / 독서실 operator

1. 손님들이 휴대폰 때문에 집중을 방해받는 문제를 실제로 이야기하나요?
2. 휴대폰 보관함이나 집중석 같은 운영을 해본 적이 있나요?
3. 손님이 휴대폰을 맡기고 수신기를 받아가는 방식이 운영상 가능할까요?
4. 가장 큰 걱정은 무엇인가요? 분실, 파손, 개인정보, 직원 업무, 위생, 충전, 소음?
5. 수신기 번호와 휴대폰 번호를 매칭하는 방식은 어느 정도까지 가능할까요?
6. 유료 옵션이면 어느 방식이 가장 자연스럽나요? 좌석 옵션, 시간당 요금, 멤버십, 무료 차별화 서비스?
7. 1~2주 작은 파일럿을 한다면 어떤 조건이 필요할까요?

## Park / program operator

1. 공원 이용자가 휴대폰 없이 걷거나 뛰는 프로그램이 의미 있을까요?
2. 공원 거점에서 휴대폰을 맡기고 수신기를 대여하는 방식이 가능한가요?
3. 운영 인력, 분실, 보관, 반납, 위생에서 가장 큰 문제는 무엇인가요?
4. 어느 위치와 시간대가 실험에 적합할까요?
5. 짧은 체험 프로그램을 만들 수 있을까요?

# 6. Evidence ladder

Weak → strong:

1. 좋다고 말함
2. 필요하다고 말함
3. 본인 문제 사례를 말함
4. 현재 해결 방법을 말함
5. 폰을 맡길 수 있다고 말함
6. 체험 의향을 남김
7. 실제 테스트 날짜를 잡음
8. 운영자/장소 연결을 제공함
9. 유료 옵션을 논의함
10. 반복 사용 또는 도입을 논의함

PR1은 최소 7단계 이상을 첫 시장검증 성공으로 본다.

# 8. GO / PIVOT / STOP

## GO

10~20명 검증 후:

- 50% 이상이 반복 phone distraction 또는 phone-carrying problem을 말함
- 40% 이상이 audio-only need를 말함
- 30% 이상이 phone deposit + receiver use를 실제로 해볼 수 있다고 말함
- 최소 3명 이상 prototype test 의향
- 최소 1개 장소 또는 운영자와 pilot discussion 가능

## PIVOT

- phone deposit은 싫지만 phone locker + audio station에는 관심이 있다
- study cafe는 약하지만 park/running이 강하다
- park는 약하지만 study cafe가 강하다
- 개인보다 시설 운영자가 더 관심 있다

## STOP / rethink

- people will not hand in phones
- audio need is weak
- receiver feels like just another device
- operators reject the exchange flow
- PR1 keeps being interpreted as earbuds
